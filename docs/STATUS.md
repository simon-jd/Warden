## 怎么跑测试

```bash
make tools          # 一次性：Go 1.26.10、Vector 0.45.0、Kyverno CLI 1.19.2、pySigma venv 放进 .tools/（优先用 .cache 里的副本）
make test           # 全部离线套件，约 1 分钟
make check          # go vet + gofmt -l + shellcheck
make test-postgres  # 需要 Docker 和本地 postgres:18-alpine 镜像；临时容器，结束即删
```

`make test` 用的都是项目内工具链：`GOTOOLCHAIN=local`、`GOPROXY=off`、项目内的 GOCACHE/GOMODCACHE/TMPDIR，Go 测试顺序随机（`-shuffle=on`）；Python 用 `-I`，不读 PYTHONPATH 和用户 site-packages。测试不读 `.cache/warden-lab` 里的旧预留，也不测量真实项目目录的大小。

`make test` 要求 Go 测试的临时目录 `.cache/test-tmp` 和它上面的每一级目录都不能被 group 或 others 写（root 的 sticky 目录，比如 `/tmp`，可以）：`runtimes/firecracker` 的 `privateRoot` 拒绝这样的上级目录（`writable private ancestor`），测试里也不放宽。umask 0002 下 clone 出来的目录、make 建的 `.cache` 都是 group 可写的；这时 `make test-go` 一开始就停（`scripts/check-test-tmp.sh`），列出这些目录和修法：对它们 `chmod go-w`，或者在 umask 022 下 clone 和运行 make。
